# MRK Travels Website

A ready-to-run responsive website for MRK Travels, Perambalur.

## Files
- index.html — website structure
- style.css — design and responsive layout
- script.js — mobile menu, booking form and WhatsApp integration

## Run in VS Code
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Install the VS Code "Live Server" extension if you want automatic browser refresh.
5. Right-click `index.html` → "Open with Live Server".
